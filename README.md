# 蝶应桌宠

Windows 桌面上的 Q 版互动伙伴，支持键鼠互动、衣装切换、表情、呼吸与头饰动作、闲置打瞌睡、托盘菜单和开机自启。

## 当前开发状态

当前运行素材包含常服与打歌服。朱慧月（黄玲琳灵魂）的两套红色衣装及新版素材正在制作，尚未接入本版本。仓库代码包含更新功能；正式安装包将在 Releases 发布，未发布时程序会明确提示。

## 使用

从 Releases 下载 `DieYing-Windows.zip`，完整解压到可写目录后运行 `DieYing.exe`。请保留同目录的 `assets`，不要仅发送 exe。设置保存在程序目录的 `data/settings.ini`。

右键打开菜单；可调整衣装、表情、大小、鼠标穿透等。键盘手只做轻微敲击，鼠标手跟随鼠标移动。连续快速输入会触发表情，闲置时会打瞌睡。

## 更新

启动时可自动检查正式版，菜单中也可手动检查。发现新版后由使用者确认下载及重启。仅接受本仓库的 Windows 包及 GitHub 提供的 SHA-256 校验值，跳过草稿、预发布与较旧版本。

更新仅替换程序与 `assets`；保留 `data` 设置，旧程序与旧素材备份在 `data/updates/<本次编号>/backup`。下载校验失败不替换文件；替换或启动进程失败尝试恢复旧版。若新版启动后才发生运行错误，仍需手动恢复备份。

## 构建

需要 Windows 和 .NET Framework 4.5 或更新版本（建议 4.8）。在 PowerShell 中执行：

```powershell
./build.ps1
./DieYing.exe --update-test checks/update-review
```

更新校验会创建隔离的测试目录，不改实际设置，不联网下载更新。完整渲染验证可运行 `--self-test <新目录>` 与 `--smoke <新目录>`，需要可用的 Windows 图形环境。

## 发布

在 `src/UpdateService.cs` 中更新 `VersionText` 后创建同版本标签（例如 `v0.2.0`）。GitHub Actions 构建并创建草稿 Release；检查素材、实际运行与升级流程后再发布草稿。

手动生成包：`./release.ps1 -Version 0.2.0`。包中只包含程序、素材和版本文件，不包含个人设置、源码、备份及测试截图。

公开仓库不自动授予角色或美术素材的再授权；素材使用范围请与维护者确认。
